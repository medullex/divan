# Общий диван

Совместный просмотр видео в браузере. Ведущий комнаты включает видео с Rutube, VK Видео
или загружает фильм со своего компьютера, и оно появляется у всех в комнате.
Пауза и перемотка ведущего действуют на всех. Есть чат, реакции, очередь, аккаунты и друзья.

## Как пользоваться

1. Откройте сайт, введите имя и нажмите «Создать комнату». Вы ведущий.
2. Нажмите «Скопировать ссылку» и отправьте друзьям.
3. Найдите фильм на Rutube (или вставьте ссылку на VK Видео), либо нажмите «загрузить фильм с компьютера».

## Фильм с компьютера

- Файл загружается на сервер; все в комнате видят проценты, после загрузки фильм открывается у всех.
- Лучше всего MP4 (H.264/AAC): его понимают все браузеры, включая iPhone. MKV и AVI на iPhone не откроются.
- Файл временный: он удаляется, когда загрузивший уходит из комнаты (через 20 секунд — на случай перезагрузки
  страницы) или выбирает другое видео. Не закрывайте вкладку, пока смотрите.
- Предел размера — переменная `MAX_UPLOAD_MB` (по умолчанию 2500 МБ).

## Запуск на своём компьютере

Нужен Node.js 18+. В папке проекта: `npm start`, затем откройте http://localhost:3000

## Хостинг

Работает на любом хостинге с Node.js и WebSocket (Render, Railway, свой VPS).
Сервер слушает порт из переменной `PORT`. Внешних зависимостей нет.
На бесплатном Render загруженный фильм стирается при перезапуске или «засыпании» сервиса.

## Про авторские права

За то, что показывает ведущий, отвечает ведущий: показывайте видео, на которые у вас есть права.
Загруженные файлы доступны только по случайной ссылке внутри комнаты и удаляются после просмотра.
