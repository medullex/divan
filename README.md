# Общий диван

Совместный просмотр видео в браузере. Каждый открывает **свой** видеофайл, а между зрителями
передаются только пауза, перемотка, время, чат и реакции. Видео через сервер не проходит и никуда
не загружается.

Работает с телефона и компьютера, регистрация не нужна. Внешних зависимостей нет, нужен только Node.js 18+.

## Что умеет

- Комнаты по ссылке вида `https://ваш-сайт/r/abcd-1234`
- Общие пауза, плей и перемотка: кто угодно нажал, у всех то же самое
- Опоздавший сразу попадает в нужный момент
- Чат с отметкой времени в фильме и реакции
- Список зрителей: видно, кто выбрал файл и не отличается ли он по длительности
- Свои субтитры (.srt или .vtt)

## Запуск на своём компьютере

1. Установите Node.js с https://nodejs.org (версия LTS).
2. Откройте папку проекта в терминале и выполните:
   ```
   npm start
   ```
3. Откройте http://localhost:3000

Так можно смотреть с людьми в одной домашней сети Wi‑Fi: они открывают `http://IP-вашего-компьютера:3000`.
Чтобы позвать друзей из других городов, выложите сайт в интернет (ниже).

## Как выложить бесплатно (Render)

1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий (кнопка **New**).
2. На странице репозитория нажмите **uploading an existing file** и перетащите туда все файлы
   из этой папки: `server.js`, `miniws.js`, `package.json`, `render.yaml`, `README.md` и папку `public`.
   Нажмите **Commit changes**.
3. Зарегистрируйтесь на https://render.com (можно войти через GitHub).
4. Нажмите **New → Web Service**, выберите ваш репозиторий.
5. Проверьте настройки:
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: **Free**
6. Нажмите **Create Web Service** и подождите пару минут. Сверху появится адрес вида
   `https://obshchiy-divan.onrender.com` — это ваш сайт.

На бесплатном тарифе сервер засыпает после 15 минут без зрителей. Первое открытие после этого
занимает около минуты, дальше всё работает быстро.

Подойдёт и любой другой хостинг с Node.js и поддержкой WebSocket (Railway, Fly.io, свой VPS).
Сервер слушает порт из переменной окружения `PORT`.

## Какие файлы откроются

Всё, что умеет браузер: надёжнее всего MP4 (H.264 + AAC), WebM. MKV открывается не везде
(в Chrome часто да, в Safari нет). Если файл не открывается, переконвертируйте его в MP4.

## Про авторские права

Сервис сам ничего не раздаёт: на сервере нет видео, есть только команды плеера. Смотрите файлы,
на которые у вас есть права: купленные, свои или распространяемые по свободной лицензии.
